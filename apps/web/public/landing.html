Attendance, without the proxy problem

Mark a full class in seconds, not minutes.

A lecturer starts a session and shows a QR code that refreshes every 30 seconds. Students sign in on their phones and scan it. The record is sealed the moment check-in closes.

Get started See how it works

Rotating QR check-in

Short-lived, signed codes refresh every 30 seconds, so a screenshot passed to a friend is already stale. The lecturer can cancel codes on screen at any time.

Anti-proxy controls

A room headcount, randomised in-person spot checks and a review trail catch stand-ins — all as review signals for the lecturer, never automatic penalties.

One device, one student

A phone that has already checked one student in cannot quietly check in another for the same class.

Course attendance history

Every session rolls up per course for both lecturers and students, with exports to CSV, Excel, PDF and Word.

Optional face verification

An opt-in pilot, off by default and enabled per course. It is a review signal only, needs the student's consent, and never stores a raw image.

Built to be trusted

The database — not the app — enforces the rules. No precise location is collected, and nothing is written to official university systems.
