Built for real lecture halls

Fast for an honest student, awkward for a proxy, and trustworthy for the record.

Rotating QR check-in

Short-lived signed codes refresh every 30 seconds, so a screenshot passed to a friend is already stale. The lecturer can cancel codes on screen at any time.

Anti-proxy controls

A room headcount, randomised in-person spot checks and a review trail catch stand-ins — as review signals for the lecturer, never automatic penalties.

One device, one student

A phone that has already checked one student in cannot quietly check in another for the same class.

Course attendance history

Every session rolls up per course for lecturers and students, with exports to CSV, Excel, PDF and Word.

Optional face verification

An opt-in pilot, off by default and enabled per course. A review signal only, needing the student's consent — and it never stores a raw image.

Built to be trusted

The database — not the app — enforces the rules. No precise location is collected, and nothing is written to official university systems.

From opening a session to a record you can stand behind.
